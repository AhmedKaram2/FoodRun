## Codex integration guidance
1. Use coral (#FF684A) as the main CTA/brand color.
2. Use charcoal (#1F2937) for primary text.
3. Use cream (#FFF7ED) for warm section backgrounds.
4. Use green (#22C55E) as a secondary positive/accent color.
5. Use Poppins for headings/buttons when available.
6. Prefer rounded cards, generous whitespace, and soft shadows.
7. Keep the brand friendly and social rather than restaurant-specific.
8. The core product message is group ordering + fair/easy splitting.
